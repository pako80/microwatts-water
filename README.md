# Micro WatTS

Static website for the **Micro WatTS** project — *Micro Wastewater Treatment Systems using Photocatalytic Surfaces*.

A 2.5 million Euro project co-financed by INTERREG V.A. Italia-Malta.

## Structure

```
├── index.html          # Home
├── about/              # About the project
├── news/               # News articles
├── people/             # Team members
├── contact/            # Contact page
├── research/           # Research pages
├── style.css           # All styles
├── Micro_WatTS_logo_RBG.svg
├── hero1_leaf.jpg
└── wp-content/uploads/ # Images (news + people portraits)
```

## Hosting

This site is hosted as a static site — no server-side code required.
Compatible with GitHub Pages, Vercel, or Netlify.
